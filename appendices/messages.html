    Appendix A: Message and Event Reference¶

    Message kinds¶

    Kind Left bar colour On screen for Needs acknowledging?
    Information Your broker's accent colour (orange by default) About 4 seconds No
    Success Green About 4 seconds No
    Warning Amber About 4 seconds No
    Error Red About 6 seconds No
    Critical (margin calls on your account) Red window in the middle of the screen Until you press Dismiss or View Position Yes

    At most seven small messages are shown at once; older ones give way to newer. An identical message repeated within two seconds is shown only once. Critical windows are not counted in the seven and never disappear by themselves.

    When Show notifications is off (Settings → Trading), the small messages are not shown at all. Critical windows are still shown.

    Complete message list¶

    Everything the application can tell you, grouped by kind. Values in angle brackets are filled in at the time. Where a message has a second line, it is shown after a dash (—).

    Critical (stays on screen until you dismiss it)¶

    Message When
    Margin Call for Account — Margin Call Level 1!… Equity has fallen below used margin
    Margin Call for Account — Margin Call Overdue!… The margin-call grace period expired
    Margin Call for Account — MC Levels: Hedge All… Positions were hedged automatically
    Margin Call for Account — MC Levels: Close All — All open postions are closed! The most severe margin call. Every position was closed. (The spelling is as shipped)
    Margin Call for Account — Margin Call!… Some positions will be closed
    Margin Call for Account — Margin Call released!… The account recovered
    Short Margin for Account — Short Margin!… Balance has fallen below used margin
    Short Margin for Account — Short Margin Overdue!… The short-margin period expired
    Margin Call on account #. The following open positions are closed:… Your broker closed positions. The full list follows

    Success¶

    Message When
    Buy @ A market order placed from the chart strip or Living Market was accepted
    Sell @ As above, for a sell
    Order placed — # An order was accepted
    Order placed An order was accepted but the broker returned no reference
    Position # closed A position was closed
    Position closed A position was closed with no reference returned
    Order Executed — Buy An order was filled and a position opened. Size, price and trade number appear beneath
    Connected — live prices Reconnected after an interruption
    Feed restored — queued order(s) submitted as pending Held orders were sent after an outage
    Exported rows to CSV An export succeeded. The file path appears beneath
    Template saved A chart template was saved
    Account added successfully A new account was added
    Account removed An account's stored credentials were deleted
    Password changed Your password was changed
    Updated instrument(s) A bulk order-distance change was applied
    Clone created An editable copy of a supplied strategy was made
    Back-test complete A back-test finished. A summary appears beneath (shown as a warning if some symbols failed)

    Information¶

    Message When
    Order cancelled A pending order was removed
    Stop loss updated A stop-loss was changed by dragging it on the chart
    Take profit updated A take-profit was changed by dragging it on the chart
    Order rate updated A pending order's trigger price was changed by dragging
    Order modified An order, stop or limit was changed from a dialog
    Chart setup updated on another device Your chart settings changed elsewhere. Switch instrument or reopen the chart to load them
    Alt+E — focus a list first Alt+E was pressed on the Summary tab with no table selected
    Action cancelled A voice instruction was cancelled at the confirmation step
    Charts off — chart window(s) closed You switched charts off and open chart windows were closed
    Version is available A newer version can be downloaded from Help on the right-hand strip
    User manual coming soon F1 or a manual link was used where your broker's manual is not yet available

    Message When
    Offline mode — simulated prices Your session was lost and the application is logging you back in; prices are not live
    No Feed: lots queued — will submit when feed restores An order was placed while disconnected and is being held
    Price Alert: The rate has reached A price alert triggered
    Price alerts are unavailable: the broker's alert server could not be reached. Your price alerts could not be loaded
    Account . Equity has reached

    % of Used Margin.

    		 Early equity warning
    Account . Equity has reached the minimum. Equity is at the account minimum
    Closed trades could not be loaded The Closed tab's history request failed. The reason appears beneath
    Chart window limit reached You already have the maximum number of chart windows open
    No rows updated (checked rows' broker minimum exceeds the value). A bulk distance change matched nothing
    Not saved — broker minimum is pips for this instrument A distance below the broker's minimum was rejected
    Symbol limit reached A strategy already watches the maximum number of symbols
    Watchlist is empty You tried to fill a strategy's symbols from a watchlist with no instruments
    Watch list limited to symbols Only the first symbols of a watchlist were added to a strategy
    Chart symbol unchanged A running strategy's first (chart) symbol cannot change until you stop and run it again

    Error¶

    Message When
    Order failed An order was rejected. The reason appears beneath (see below)
    Wrong Account Type or Username or Password Login credentials were not accepted
    This broker's server rejected the login due to a server-side error… A fault on your broker's server
    Login failed — the server returned an unexpected response… The login reply could not be understood
    Order failed — No instrument selected — select a symbol first A chart trade with no instrument loaded
    Order failed — No live price for A chart trade with no price available
    Invalid price — Chart produced an invalid price value — drag cancelled A dragged level was not usable
    Order not found — Order # may have been filled or cancelled The dragged order no longer exists
    Position not found — Position # may have already been closed The dragged position no longer exists
    Unsupported chart action — This chart action isn't recognized — please use the position/order panel instead The chart sent an action the application does not handle
    Invalid lot size The trade size in the chart strip was zero or unusable
    No live price for A chart-strip or Living Market trade was attempted with no price
    No instrument selected A chart-strip trade was attempted with no instrument
    is not available on this broker A Living Market instrument your broker does not offer
    Cannot resolve instrument id for A Living Market instrument could not be matched to your broker's list
    The price alert could not be saved. Your broker did not accept a price alert. Any reason is added after a colon
    Price alerts are not available right now. An alert was added or changed while the alert service was unavailable
    Unknown instrument A price alert's instrument could not be matched
    Export failed A CSV export could not be written. The reason appears beneath
    Password change failed Your broker rejected the password change
    Action failed A voice instruction could not be carried out
    Clone failed A copy of a strategy could not be created
    Back-test failed A back-test failed for every symbol

    ActAI and the Reports tab also show messages headed "ActAI Generator" or with the text the report page reported — these describe what happened in that panel.

    Reasons shown beneath "Order failed"¶

    Besides your broker's own wording, you may see:

    Reason Meaning
    The amount must be not less than and not more than lots The size is outside the instrument's limits
    The amount must be a multiple of Trade Step. Trade Step on is lots The size is not a whole number of steps
    Rate must be at least pips from the current market price A pending order or stop/limit is too close to the market
    Buy Limit must be below Ask / Buy Stop must be above Ask / Sell Limit must be above Bid / Sell Stop must be below Bid The entry price is on the wrong side of the market
    Stop Loss for a Buy position must be below the current market () And the matching messages for Sell positions and Take Profit
    Trailing distance must be at least pips The trailing stop is too tight
    position(s) could not be closed — no live price for . Close them individually or try again. A bulk close skipped positions with no current price
    Session expired — reconnecting… Your session ended; the application is logging you back in
    Server did not respond in time — please try again The broker did not answer
    This is a read-only (customer) account. Trading actions are not permitted. Your account can view but not trade
    Account not ready — the server has not returned a numeric account ID… Your account details have not loaded yet
    Rate limit: too many order requests per second — this request was rejected… A strategy sent orders too quickly

    Quick Trade notes inside the watchlist¶

    With Quick Trade on, these appear briefly inside the watchlist rather than in the corner:

    Note When
    Buy placed / Sell placed A one-click order was accepted
    No price available for There is no current price to trade at
    Invalid lot size for The size in the row is zero or unusable
    The amount must be not less than and not more than lots The size is outside the instrument's limits
    Order failed, or your broker's reason The order was rejected

    Events and Messages log¶

    Trading, margin and connection messages above are also recorded on the Summary tab, along with entries that appear only in the log. Login errors are not recorded — they stay on the login screen. The Source column tells you where an entry came from:

    Source Meaning
    Your trader ID An action you took
    Strategy: An action taken by that ActFX strategy
    Leader: A position copied from that leader
    Information Login, logout and connection events
    SYSTEM Generated by your broker's server
    EXCEPTION An error or a rejected order
    Warning An equity or margin-call notice

    Entry formats:

    Log entry Meaning
    Order Placed: # An order was accepted
    Order Cancelled: # An order was removed
    Order Triggered: # A pending order's price was reached
    Position Opened: Ticket # A position opened. Time, side, instrument, size and price follow
    Position Closed: Ticket # A position closed. Side, instrument, size and opening price follow
    Your order # to lot at was executed at A conditional order filled
    Trader has logged on from
    .
    		 A login was recorded
    Duplicate logon using your user ID from
    		Your credentials were used to log in elsewhere
    Trader has logged off. A logout was recorded
    Login You connected
    Logged out You disconnected

    The log holds the most recent 2,000 entries and is kept between sessions.

    Sound events¶

    Each event below plays its own short sound. You can switch each one on or off, and set the volume, in Settings → Trading. No sound plays while Show notifications is off.

    Event Plays when
    Order placed An order is accepted
    Order filled A new position opens — a market order, or a pending order whose price was reached
    Position closed A position closes
    Order rejected / failed An order is refused
    Price alert triggered An alert fires
    Margin call A margin-call message arrives for the account, including "Margin Call released". Equity warnings do not play a sound
    Feed / connection lost The price feed drops
